# Roadmap

High-level direction lives in [`PLAN.md`](./PLAN.md). This file is a short public summary.

## Now (0.1.x)

- Solidify VFS + file manager DX
- npm install reliability (cache, scoped packages)
- Grow Node builtin coverage used by real tooling
- Keep demo responsive and honest about limits

## Next

- Stronger WASM kernel path as default (parity with JS fallback)
- OPFS / persistence across refresh
- Deeper Vite-in-browser path (beyond esbuild-wasm demos)

## Later

- Substantive Next.js subset in-tab
- Package publishing + versioned docs site

Non-goals remain listed in `PLAN.md` (native addons, full POSIX, raw TCP, perfect Node parity).
